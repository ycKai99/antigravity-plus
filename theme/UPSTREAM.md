# Theme source

The theme CSS, session-metrics decoder, and parts of the browser/CDP runtime are
adapted from [Anarcadia/chuanban-antigravity-theme-patch](https://github.com/Anarcadia/chuanban-antigravity-theme-patch),
version 5.0.0, commit `b319dba8dcc4f8b5bef38aef810cb530ace192a8`.

This integration omits the translation engine and dictionary. Font families
remain controlled by Antigravity Plus's existing `font` module. Runtime cleanup,
CDP script replacement, configuration validation, and process management are
adapted for this project's runner. Upstream source at this commit has no LICENSE
file; this attribution does not assign it the root project's MIT license.
